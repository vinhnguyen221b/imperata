# Imperata brand

The logo is a broken hexagon round an I, with a red point below, beside the word IMPERATA. It is drawn as clean vector shapes.

| Standalone symbol | [`imperata-icon.svg`](imperata-icon.svg) · [`PNG`](imperata-icon.png) | Transparent, bone white and red; for dark surfaces |
| Symbol for light surfaces | [`imperata-icon-on-light.svg`](imperata-icon-on-light.svg) · [`PNG`](imperata-icon-on-light.png) | Transparent, dark ink and red |

| Small icon | [`imperata-app-icon-32.png`](imperata-app-icon-32.png) | 32 px preview / favicon |

Colors: bone `#F2F0E9`, ink `#1A1A19`, red `#E84C3D`. The letters of the logo are drawn as vector paths (no font needed), with an I that repeats the monogram's serifs.

In use: the logo with its wordmark heads the repository's `README.md` (dark and light variants), and the run board shows it in its header, in the theme's ink, with the app tile as the tab icon (`starter/scripts/render-run-board.mjs`, `starter/scripts/board-server.mjs`). Those copies are inline, so a change to the artwork here must be made there too.
